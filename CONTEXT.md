# Reading together

A child and parent work through the supplied reading curriculum together. The book defines the teaching content; the parent delivers it and judges the child's responses.

## Language

**Curriculum**:
The ordered lessons, exercises, and teaching instructions supplied from the book.
_Avoid_: Reading.com curriculum.

**Lesson**:
A numbered unit of the book containing an ordered set of tasks.
_Avoid_: Screen, activity, individual response.

**Task**:
A titled exercise within a lesson, including its source steps, examples, repetitions, and corrections.
_Avoid_: Screen, individual response.

**Task run**:
One delivery of a task's teaching sequence, including its responses, repetitions, corrections, and unfinished position. Pausing and resuming the same delivery does not create another run.
_Avoid_: Response attempt, screen, ambiguous “attempt.”

**Source step**:
A numbered instruction in the supplied book, which may contain several teaching actions or responses.
_Avoid_: Screen, application turn.

**Response**:
A child's spoken, pointing, tracing, or writing action in response to a teaching prompt.
_Avoid_: Task completion, mastery.

**Response attempt**:
One try at the requested response within a task run.
_Avoid_: Task run, task completion, ambiguous “attempt.”

**Teaching turn**:
A meaningful unit of parent-led teaching that the parent advances through, with associated setup and praise kept together where applicable. A source step and a teaching turn need not have the same boundary.
_Avoid_: Sentence, screen, source step.

**Advance**:
The parent's acceptance of the current teaching turn and movement to its next prescribed position.
_Avoid_: Automatic passing, mastery.

**Back**:
Revisiting earlier teaching without withdrawing an accepted advance.
_Avoid_: Undo advance, reset.

**Undo advance**:
Withdrawing the latest parent acceptance after an accidental advance, including an accidental task completion, while keeping saved writing and earlier valid completion credit.
_Avoid_: Back, undo stroke, replay.

**Correction**:
A supplied support sequence that addresses a response and returns the child to the prescribed practice or retest.
_Avoid_: Failure score, punishment.

**Task completion**:
The parent's acceptance that the task's required teaching sequence has been delivered.
_Avoid_: Mastery, optional writing skip.

**Mastery**:
The child's acquired reading skill, distinct from having completed a teaching sequence.
_Avoid_: Task completion, tap count, drawing coverage.

**Writing skip**:
The parent's explicit choice to omit an optional sound-writing task.
_Avoid_: Writing completion, mastery.

**Child profile**:
One child's separate progress, saved writing, and unfinished teaching context on a shared device.
_Avoid_: Parent account, household, device.

**Parent override**:
An explicit parent choice to open available teaching outside the recommended sequence, without declaring unseen work complete.
_Avoid_: Completion, mastery, automatic unlock credit.

**Backup**:
A parent-created passphrase-protected portable copy of saved progress, writing/history, unfinished task runs and Undo, preferences, and the exact approved runtime content needed for offline recovery.
_Avoid_: Cloud sync, autosave, local restart recovery.

**Restore**:
Validating a protected backup and bringing its work into new local profile identities after parent preview/rename, without silently merging or overwriting existing work.
_Avoid_: Replay, restart lesson, reset.

**Source wording**:
Words verified against the supplied book, including its spoken scripts and parent instructions.
_Avoid_: Unverified transcription, newly written interface copy.

**Added wording**:
Interface wording introduced by the application rather than copied from verified book text.
_Avoid_: Source wording, book script.
