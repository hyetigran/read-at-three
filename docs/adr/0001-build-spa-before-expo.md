# Build the complete React SPA before adapting to Expo

**Status:** Accepted development decision from October 15, 2026; public-release role confirmed October 16, 2026.

Implement the full application and core logic first as a React SPA for faster development, then adapt it to React Native with Expo for multiplatform distribution. Share TypeScript curriculum, session, progress, canonical ink, and Drizzle SQLite contracts while keeping web/native screens and platform adapters separate. The SPA is the full development application; Expo is the first public release, and permanent public web support is not a launch commitment. This accepts later UI/adapter work in exchange for the preferred initial development workflow without making the SPA disposable; see the accepted [interview decisions](../design-interview.md).
