# Separate Back navigation from Undo advance

**Status:** Accepted by the user on October 16, 2026.

Back revisits earlier teaching; a distinct parent Undo last advance withdraws a mistaken acceptance, including a just-completed task. Undo may step back through the current task run to its start and remains available across restart; starting another run for that child closes the previous undo window. Preserve saved ink and completion credit from earlier valid runs instead of requiring a profile reset or pretending replay corrects false completion. This deliberately adds acceptance-reversal semantics to the earlier monotonic-result proposal; the revised persistence contract must implement the accepted [interview decisions](../design-interview.md).
