# Recommend the curriculum sequence with parent overrides

**Status:** Accepted by the user on October 16, 2026.

Recommend the book's lesson sequence while permitting an explicit parent override to enter available lessons or tasks outside that sequence. Earlier unseen work stays incomplete, and normal delivery within a selected task preserves its required turns: access is a navigation choice, distinct from parent-confirmed task completion or mastery. This favors parent agency over mandatory lesson locks while preserving truthful progress; the accepted scope and dependent progress behavior are recorded in the [design interview](../design-interview.md).
