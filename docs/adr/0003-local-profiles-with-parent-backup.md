# Local child profiles with parent-controlled backup

**Status:** Accepted by the user on October 16, 2026.

The initial public Lessons 1–6 release is free and uses separate local child profiles without login, purchases or cloud sync. Include passphrase-protected parent export/import backup containing saved work, unfinished context and approved runtime content needed for offline recovery; exclude original scans/development artifacts. Restore as new profiles with preview/rename instead of silently merging by name or overwriting work. This preserves offline use and avoids account/service dependencies while making backup creation and passphrase retention parent responsibilities; engineering must validate the format and protection described by the [interview](../design-interview.md).
